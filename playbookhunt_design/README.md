# Design handoff

Start with CURRENT_DESIGN.md. It records the latest agreed behavior and overrides older visual references where they differ.

- png/: original desktop/mobile frames for layout and visual style.
- assets/muse-avatar.png: current avatar asset; assets/agents/: other agent marks, source notes, and license.
- 01_homepage.html, styles.css, draw_frames.py, render.swift: historical mockup/rendering sources, optional for the new builder. These do not implement the application.

No current-user screenshots or evidence files are included. The original mockups contain illustrative outcome numbers, not actual results.
